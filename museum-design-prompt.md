# Промпт для оформления любого музейного экспоната

## Задача

Примени к этому проекту единую дизайн-систему музея ЧГУ им. А. А. Кадырова. Проект может быть квизом, картой, архивом, интерактивной историей, фотозоной, видеоплеером или 3D-сценой.

Сохрани его назначение, содержание, данные и рабочую функциональность. Не превращай его в копию другого экспоната: едиными должны быть визуальный язык и правила взаимодействия, а композиция должна отвечать задаче.

## Характер

Современный музей, спокойная ясная подача, уважение к историческим материалам.

Без вычурной торжественности, неона, золотых градиентов, стеклянных карточек, декоративных частиц, постоянного свечения и бессмысленных украшений.

## Палитра

| Назначение | Цвет |
|---|---|
| Основной фон | `#111C19` |
| Панели | `#192823` |
| Приподнятые / активные поверхности | `#21352D` |
| Основной текст | `#F3EFE5` |
| Вторичный текст | `#B9C4BA` |
| Акцент — приглушённая латунь | `#C9AD79` |
| Наведение / фокус | `#DFC394` |
| Декоративные разделители | `#35463C` |
| Контуры интерактивных полей | `#718276` |
| Успех | `#9BCCA9` на фоне `#253F31` |
| Ошибка | `#E0A59C` на фоне `#42302A` |

Используй латунь дозированно, прежде всего для главного действия и активного состояния.

Не перекрашивай смысловые данные карты или естественные цвета фото механически: фирменный стиль применяется прежде всего к оболочке и управлению.

## Шрифты

- **Literata Regular** — для заголовков и крупных акцентных чисел.
- **Manrope Regular / Semibold** — для текста, интерфейса и данных.

Прямые начертания, поддержка кириллицы, локальные файлы шрифтов с лицензиями.

| Параметр | Значение |
|---|---|
| Заголовки | 28–88 px в зависимости от уровня |
| Основной текст | 16–22 px |
| Служебные подписи | 12–14 px |
| Межстрочный интервал заголовков | 1.15–1.25 |
| Межстрочный интервал текста | 1.45–1.6 |

Не применять шрифт с засечками ко всему интерфейсу.

## Логотип

Используй приложенный прозрачный логотип без перерисовки и искажения.

- Белая версия — на тёмном фоне.
- Охранное поле — не меньше четверти высоты логотипа.
- Не использовать картинку с нарисованной шахматной «прозрачностью».
- Если настоящего прозрачного файла нет, запроси его.

## Сетка и геометрия

- Сетка отступов: **4/8 px**.
- Основные интервалы: **16/24/32/48/64 px**.
- Радиусы:
  - кнопки — **8 px**;
  - поля — **10 px**;
  - карточки — **12 px**;
  - панели — **16 px**.
- Разделители: **1 px**.

Спокойные плоские поверхности без обязательных теней и размытия. Вид и количество панелей определяются содержанием, не шаблоном.
