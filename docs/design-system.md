# Дизайн-система в коде

Первоисточник правил — [`museum-design-prompt.md`](../museum-design-prompt.md).
Это единая дизайн-система экспонатов музея ЧГУ им. А. А. Кадырова, одна и та
же для всех проектов музея (например, для `akhmatmap`). Здесь описано, **как
эти правила реализованы в «Экспонатах ЧР»** и как их не нарушить при
изменениях.

Характер: современный музей, спокойная ясная подача, уважение к историческим
материалам. **Нельзя:** неон, золотые градиенты, стеклянные (полупрозрачные)
карточки и кнопки, декоративные частицы (в том числе `InkSparkle`), постоянное
свечение, тени и размытие «для красоты», подъём карточек при наведении.

## Где что лежит

| Что | Файл |
|---|---|
| Токены: цвета, шрифты, отступы, радиусы, ассеты | `lib/core/theme/tokens.dart` |
| Тема Material 3: текст, кнопки, поля, тултипы, скроллбар | `lib/core/theme/app_theme.dart` |
| Общие компоненты | `lib/ui/widgets/common.dart` |
| Шрифты и лицензии OFL | `assets/fonts/`, подключены в `pubspec.yaml` → `fonts` |
| Логотип | `assets/images/brand/logo_white.png` → `AppAssets.logoWhite` |

`app_theme.dart` реэкспортирует `tokens.dart`: достаточно импортировать
`core/theme/app_theme.dart`.

**Правило:** в виджетах не должно быть hex-литералов, `Colors.white`/`black`,
«магических» отступов и радиусов. Только токены и `context.text.*`.
Исключение: `Colors.transparent`.

## Палитра — `AppColors`

| Токен | Цвет | Назначение |
|---|---|---|
| `background` | `#111C19` | основной фон: Scaffold, полноэкранные режимы, подложка под фото |
| `panel` | `#192823` | панели и карточки в покое, 3D-сцена, метки и кнопки поверх медиа |
| `raised` | `#21352D` | наведение и выбранное состояние карточек, тултипы, заглушки превью |
| `textPrimary` | `#F3EFE5` | основной текст, заголовки, описание экспоната |
| `textSecondary` | `#B9C4BA` | вторичный текст, подписи секций, метаданные, иконки |
| `brass` | `#C9AD79` | акцент: **только** главное действие и активное состояние |
| `brassHover` | `#DFC394` | наведение и фокус у кнопок и полей, активный делитель |
| `divider` | `#35463C` | разделители 1 px, контуры панелей и карточек в покое |
| `outline` | `#718276` | контуры интерактивных элементов: поле поиска, кнопки, карточка при наведении |
| `success` / `successBg` | `#9BCCA9` / `#253F31` | успех (пока не используется) |
| `error` / `errorBg` | `#E0A59C` / `#42302A` | ошибка загрузки каталога |

**Латунь сейчас используется только здесь:** рамка и иконка активного
раздела, рамка выбранной плитки в ленте «Модели», рамка выбранной миниатюры
фото, `FilledButton` «Повторить», индикаторы загрузки, курсор поля. Больше не
добавляйте без веской причины. Признак «3D» на карточках нарочно нейтральный,
иначе латунь была бы на каждой карточке.

**Фото и модели не тонируются.** Фирменный стиль относится к оболочке и
управлению. Музейные снимки показываются с `BoxFit.contain` там, где важно
не обрезать предмет (галерея, сцена без модели, лайтбокс).

Тема одна, тёмная. Палитра и белый логотип рассчитаны на тёмный фон, поэтому
светлой темы нет.

## Шрифты — `AppFonts`

| Семейство | Файлы | Где |
|---|---|---|
| `Literata` (Regular 400) | `Literata-Regular.ttf` | только заголовки и крупные числа: стили `display*` и `headline*` |
| `Manrope` (Regular 400 / SemiBold 600) | `Manrope-Regular.ttf`, `Manrope-SemiBold.ttf` | весь интерфейс, текст, данные |

Шрифт по умолчанию в теме — Manrope. Используйте только веса 400 и 600 (у
Literata — только 400): других файлов нет, и Flutter нарисовал бы синтетическое
начертание.

### Шкала `textTheme`

| Стиль | Шрифт | Размер / межстрочный | Где применяется |
|---|---|---|---|
| `displayLarge/Medium/Small` | Literata | 64 / 48 / 40 | резерв |
| `headlineLarge` | Literata | 36 / 1.2 | название экспоната (широкий экран) |
| `headlineMedium` | Literata | 32 / 1.2 | резерв |
| `headlineSmall` | Literata | 28 / 1.2 | название в шапке, название экспоната (компактно), заголовок лайтбокса и полноэкранной сцены, пустое состояние |
| `titleLarge/Medium/Small` | Manrope 600 | 22 / 18 / 16 | заголовки интерфейса; `titleSmall` — название на карточке и на плашке раздела |
| `bodyLarge` | Manrope 400 | 18 / 1.55 | описание экспоната |
| `bodyMedium` | Manrope 400 | 16 / 1.5 | поле поиска, обычный текст |
| `bodySmall` | Manrope 400 | 14 / 1.45, вторичный | подзаголовок шапки, аннотация на карточке, статусы |
| `labelLarge` | Manrope 600 | 16 | кнопки |
| `labelMedium` | Manrope 600 | 14, вторичный | метаданные экспоната, плитки ленты, тултипы, счётчики |
| `labelSmall` | Manrope 600 | 12, вторичный | подписи секций (КАПСОМ, разрядка 1.2), метки `Tag`, подсказки на сцене |

Ограничения из правил: заголовки 28–88 px (межстрочный 1.15–1.25), текст
16–22 px (1.45–1.6), служебные подписи 12–14 px. **Размеров меньше 12 нет.**

## Сетка и геометрия — `AppSpacing`, `AppRadii`

- Сетка 4/8: `xxs 4`, `xs 8`, `sm 12`; основные интервалы `md 16`, `lg 24`,
  `xl 32`, `xxl 48`, `xxxl 64`.
- Боковые поля экрана: 24, компактно 16. Внутренние поля панели описания —
  те же 24/16. Зазоры в сетках и лентах — 16 и 8.
- Радиусы: кнопки и мелкие метки **8** (`button`), поля **10** (`field`),
  карточки, плашки разделов и рамка фото **12** (`card`), панели (сцена,
  описание) **16** (`panel`).
- Разделители — 1 px: `Divider()` из темы или `Border.all(color: divider)`.
- Нажимаемые элементы — не меньше 48 px (`kTouchTarget`): приложение работает
  на сенсорном киоске.
- Поверхности плоские: без `boxShadow`, `elevation: 0`, `surfaceTint`
  прозрачный. Наведение меняет цвет подложки (`panel` → `raised`) и контура
  (`divider` → `outline`) — и ничего больше.

## Компоненты

| Компонент | Вид |
|---|---|
| `SectionSurface` | панель: `panel`, радиус 16, контур `divider`, обрезает содержимое |
| `SectionLabel` | подпись секции КАПСОМ (`labelSmall`) и пояснение справа (`detail`) |
| `Tag` | непрозрачная метка поверх медиа: `panel`, радиус 8, контур `divider`, 12 px |
| `PanelIconButton` | квадратная кнопка-иконка 48 px: `panel`, контур `outline`, при наведении и фокусе — `brassHover`; всегда с `tooltip` |
| `FilledButton` | латунь с тёмным текстом, при наведении — `brassHover`. Одно главное действие на экране |
| `OutlinedButton` | контур `outline`, текст основной; при наведении контур и текст `brassHover` |
| `TextField` | заливка `panel`, радиус 10, контур `outline`, в фокусе — `brassHover` |
| Карточка / плитка | `panel`, радиус 12, `divider`; наведение — `raised` + `outline`; выбрана — `raised` + `brass` |

## Логотип

- Файл `assets/images/brand/logo_white.png`: белая версия настоящего
  прозрачного PNG (альфа-канал), 1771×681, внутри уже есть поле 32 px.
  Скопирован из проекта `akhmatmap` (тот же логотип музея).
- Показывается в шапке высотой **56 px** (компактно 48) через `_BrandLogo`,
  без перерисовки и искажения (`BoxFit.contain`, задаётся только высота).
- Охранное поле ≥ ¼ высоты (14/12 px): справа 16 px до разделителя,
  вертикальные поля шапки — 16 px, слева — боковое поле экрана (24/16).
- Только на тёмном фоне. Не использовать картинки с нарисованной «шахматной»
  прозрачностью.

## Платформенные оболочки

Цвет `#111C19` задан и вне Flutter, чтобы при запуске не мелькал другой фон:
`web/index.html` (фон страницы), `web/manifest.json` (`background_color`,
`theme_color`), Android — `res/values/colors.xml` → `launch_background`
(заставка и `NormalTheme`).

## Чек-лист

1. Цвета, отступы и радиусы — только из токенов. Отступы кратны 4.
2. Текст — стиль из `textTheme`. Literata только для заголовков и крупных
   чисел. Размер не меньше 12.
3. Латунь — не больше одного главного действия в зоне внимания плюс
   активное состояние.
4. Никаких теней, градиентов, полупрозрачных подложек, размытия, свечения,
   «подпрыгивания».
5. Кнопки ≥ 48 px, у кнопок-иконок есть `tooltip`.
6. Поверх фото и 3D — только непрозрачные `Tag` и `PanelIconButton`.
7. Проверить golden-снимки, в том числе `exhibit_phone` (390 px), и
   посмотреть PNG глазами.
