# Экспонаты ЧР

Интерактивный каталог музейной коллекции: 58 экспонатов в 6 разделах,
43 из них — с трёхмерными моделями. Flutter, сборки под **macOS** и **Android**.
Приложение полностью офлайновое: ни одна часть просмотрщика не обращается в сеть.

Оформление следует единой дизайн-системе музея ЧГУ им. А. А. Кадырова
([`museum-design-prompt.md`](museum-design-prompt.md)).

**Документация:** [docs/architecture.md](docs/architecture.md) — как устроен
проект, [docs/design-system.md](docs/design-system.md) — как правила дизайна
реализованы в коде.

## Главный экран

Три секции, как и задумано:

| Секция       | Что делает                                                                                     |
|--------------|------------------------------------------------------------------------------------------------|
| **Категории**| Плашка выбора раздела. Показывает число экспонатов и число 3D-моделей в каждом.                  |
| **Просмотр** | Пока экспонат не выбран — сетка предметов раздела. После выбора — 3D-модель слева (40 % ширины) и описание с фотографиями справа (60 %). |
| **Модели**   | Лента экспонатов раздела. Появляется только когда экспонат выбран; до этого её роль играет сетка в «Просмотре». |

Границу между сценой и описанием можно тянуть мышью, двойной клик возвращает
пропорцию 40:60. На экранах уже 900 px раскладка становится вертикальной:
сцена сверху, описание под ней.

Прочее: поиск по всей коллекции, полноэкранный просмотр
модели и фотографий с масштабированием, клавиши `←` `→` — соседний экспонат,
`Esc` — вернуться к сетке.

## Ассеты

Исходники лежат в `assets/expos/` (5.3 ГБ) и в сборку **не попадают** — это
архив, из которого скрипты собирают рабочий набор:

```
assets/data/catalog.json      описание категорий и экспонатов
assets/photos/<id>_NN.jpg     фотографии, до 1800 px          36 МБ  (было 1.4 ГБ)
assets/thumbs/<id>_NN.jpg     превью, до 640 px               4.6 МБ
assets/models/<id>.glb        3D-модели                       390 МБ (было 3.7 ГБ)
```

Имена файлов латинские: кириллица в путях ассетов ломает сборку под часть
платформ, поэтому названия папок транслитерируются в идентификаторы вида
`003-ostrokonechnyy-boevoy-shlem`. Русские названия хранятся в `catalog.json`.

### Пересборка ассетов

```bash
python3 tools/build_assets.py    # каталог, фотографии, превью; нужен Pillow
cd tools && npm install          # один раз
tools/build_models.sh            # 3D-модели; читает tools/model_jobs.json
```

Модели пережимаются `gltf-transform optimize` с квантованием геометрии
(`KHR_mesh_quantization`), WebP-текстурами 2048 px и упрощением сетки.
**Draco намеренно не используется:** встроенный в приложение `model-viewer`
подгружает draco-декодер с CDN, а приложение должно работать без сети.
Квантование и WebP декодируются штатно.

Если 390 МБ моделей слишком много, уменьшите `--texture-size` до 1024
в `tools/build_models.sh` — набор ужимается примерно втрое.

## Сборка

```bash
flutter pub get
flutter run -d macos
flutter build apk --release      # ~430 МБ: для установки в киоск, не для Play
```

Требования платформ уже прописаны: на macOS — entitlements
`network.client`/`network.server` (просмотрщик 3D работает через локальный
HTTP-сервер плагина), на Android — `INTERNET` и `usesCleartextTraffic`
для обращения к тому же localhost.

## Проверки

```bash
flutter analyze
flutter test                                        # каталог и логика состояния
flutter test test/layout_golden_test.dart --update-goldens   # снимки раскладки
```

`test/goldens/` — эталонные снимки экрана (1440×900, 820×1180, 390×844).
Плагин 3D-просмотра в тестовой среде недоступен, поэтому на снимках сцена
пустая; проверяется всё остальное.

## Структура кода

```
lib/
  core/theme/     токены дизайн-системы и тема (Literata + Manrope, одна тёмная тема)
  data/           модели данных и чтение catalog.json
  state/          GalleryState — выбор раздела, экспоната, поиск, пропорции
  ui/sections/    три секции главного экрана
  ui/widgets/     сцена 3D, описание, карточки, лайтбокс
```

Шрифты Literata и Manrope распространяются по лицензии SIL OFL 1.1
(`assets/fonts/OFL-*.txt`). Логотип — `assets/images/brand/logo_white.png`.
